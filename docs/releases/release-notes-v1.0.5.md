## qimgv v1.0.5 — EXIF 元数据编辑器

本版本新增了可直接在 qimgv 内**编辑图片元数据**的功能，并修复了若干界面缺陷。

### 新功能

**EXIF 元数据编辑器**（右键菜单，或按 `Ctrl+E`）

- **修改**：双击「数值」列即可编辑
- **删除**：选中行点「删除标签」（行加删除线标记，可点「撤销删除」恢复）
- **添加**：点「添加标签…」，在已注册命名空间下新建字段
  （dc / xmp / tiff / exif / photoshop / Iptc4xmpCore / crs / aux / lr）
- **撤回**：`Ctrl+Shift+Z`，恢复到本次编辑前的状态

### 安全性

- **编辑前自动创建快照**，且只在两种时机发生：打开编辑器时、确认保存时。
  浏览图片、翻页、按 `i` 查看信息面板**都不会**产生快照或复制文件。
- 打开编辑器但未做任何修改就关闭，快照会被立即丢弃，不占用磁盘。
- 写入元数据会重建文件中的元数据段。实现中保留了所有未被编辑的段，
  经 3 张 DJI 无人机原图验证：**26 个 `Xmp.drone-dji.*` 飞行数据与缩略图均完整保留**。
- 写入失败时原文件不受影响；撤回基于整文件快照，被删除的标签也能完整恢复。

### 修复

- **删除按钮此前必须先修改数值才可用** —— 按钮状态没有跟随选中行变化，
  现已响应选中事件，并按「该行是否已被标记删除」分别启用删除/撤销按钮。
- **Cancel 按钮此前无法关闭对话框** —— 只连接了「保存」信号，Cancel 信号无接收者，现已补上。
- **对话框未汉化** —— 补齐 8 种语言的翻译条目；同时打包 Qt 官方
  `qtbase_*.qm`，使 `QInputDialog`/`QMessageBox` 中的标准按钮也跟随界面语言。

### 安装说明

- **`qimgv-x64_v1.0.5.exe`** — 安装版（NSIS）。
  若安装时提示文件被占用，请先关闭所有 qimgv 窗口或重启后重试。
- **`qimgv-x64_v1.0.5.7z`** — 便携版，解压即用。

### 已知说明

- 添加标签仅限**已注册**的 XMP 命名空间（exiv2 拒绝未知命名空间，
  且这类标签其他软件也无法识别）。
- EXIF 标签的中文名称为内置词典，仅在中文界面下启用；其他语言显示英文原始标签名。
